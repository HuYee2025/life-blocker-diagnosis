# 人生卡点问诊

把“我知道该做什么，却总是做不到”这类模糊困惑，收窄成一个可验证的问题。它不是心理诊断工具，也不急着给建议。

## 它解决什么

适合用于：拖延、长期项目推进困难、学习难以转化、反复换方向，以及职业、创作、健康、关系或金钱决策中的持续卡点。

核心目标不是解释一个人的人格或成长经历，而是找出：在什么条件下，哪个变量变化会让行为也变化。

不适合用于紧急安全风险、医疗或法律判断，或用户只想直接获得一个方案的场景。

## 工作原理

问诊最多进行 6 问，并始终一次只问一个问题：

1. 从“我懒”“我执行力差”等标签回到近期、可还原的事件。
2. 补全当时的选择：本来要做什么、实际做了什么、什么取代了原任务。
3. 找反例，避免把情境问题误判为人格问题。
4. 比较成功与失败场景，寻找会改变行为的变量。
5. 至少进行一次只改变一个变量的反事实测试。
6. 信息足够即停止，输出诊断报告，不为了凑题而继续追问。

报告严格区分四类信息：

- 已确认事实：可观察的事件、行为、时间与结果。
- 未验证假设：对原因的暂定解释，并写明可能推翻它的证据。
- 关键变量：当前最可能改变结论的一个条件。
- 新问题：下一步可由现实实验验证的问题。

只有用户确认“新问题”准确后，才进入处方阶段。处方只包含一个暂定机制和一个最小现实实验，不堆叠方法、书单或励志口号。

## 如何使用

将 `SKILL.md` 和 `agents/openai.yaml` 安装到 Codex Skills 目录后，直接说：

```text
请用人生卡点问诊帮我分析。不要先给建议，一次只问一个问题。
我现在的困扰是：[一句话描述]。
最近一次具体发生在：[时间]；我本来要做[任务]，实际做了[行为]，结果是[结果]。
```

回答时优先给事实，不必急着解释原因。每次只处理一个卡点；例如先研究“为什么重要却不行动”，不要同时把学习、家庭、金钱和职业方向混在一轮问诊里。

## 交付物

完整问诊会给出：

1. 固定文字诊断报告：原问题、真正问题、已确认事实、未验证假设、关键变量、新问题。
2. 竖版 A4「核心诊断」图片：用于打印和复看，只呈现事实与明确标记的假设。
3. 在用户确认新问题后，给出一个最小、可验证的现实实验。
4. 竖版 A4「验证处方」图片：呈现实验的触发条件、最小动作、记录项，以及支持或推翻假设的结果。

图片报告必须使用本次问诊证据，不添加未经验证的动机、病因或人格判断。

## 安装

复制以下结构到本机 Codex Skills 目录：

```text
life-blocker-diagnosis/
├── SKILL.md
└── agents/
    └── openai.yaml
```

重启或刷新 Codex 后，可使用 `$life-blocker-diagnosis`，或直接说“请用人生卡点问诊”。
